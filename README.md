# Virtu Launcher — Windows releases

Готовые переносимые Windows-комплекты Virtu Launcher и подписанный список обновлений. Исходники самого лаунчера хранятся отдельно в закрытом репозитории.

Архивы предназначены для Windows10/11 x64. Распакуйте всю папку и откройте `Virtu Launcher.exe`. На новом ПК список шлемов пустой. Игры, регистрации устройств, ключ владельца и личные VPN-профили в дистрибутив не входят.

Пульт на планшетах работает через постоянно включённый Windows-ПК в основной локальной сети клуба. Видео Quest→TV/браузер передаётся напрямую без звука; Windows обслуживает управление и сигнализацию.

Кнопка «Обновить» получает подписанный feed `preview.json`, проверяет подпись, версию и SHA256 готового архива, сохраняет данные клуба и подготавливает новую папку установки. На клубном ПК Git не нужен.

В комплекте сохранены лицензии сторонних компонентов и исходники открытого VPN-компонента в `sources/virtu-vpn-source.zip`. Они не содержат личного профиля VPN. Приватный ключ подписи выпусков никогда не размещается в этом репозитории.

Релизы относятся к каналу preview. Аппаратная совместимость отдельных телевизоров и прошивок Quest проверяется отдельно; наличие APK не означает проверку каждой модели.
